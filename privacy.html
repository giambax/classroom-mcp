Informativa sulla privacy

Ultimo aggiornamento: 23 ottobre 2026.

Chi usa l'app

Classroom MCP è usata esclusivamente dal suo autore, con il proprio account Google. Non raccoglie dati di altre persone.

Quali dati legge

Con permessi di sola lettura: elenco dei corsi Google Classroom, compiti e relative consegne, annunci e materiali dei corsi; messaggi della casella Gmail dell'autore.

Dove finiscono i dati

I dati vengono letti direttamente dalle API di Google sul computer personale dell'autore e usati solo per mostrargli promemoria e riepiloghi. Non vengono venduti, condivisi con terzi, usati per pubblicità né caricati su server dell'app (l'app non ha server). I token di accesso restano salvati solo su quel computer.

Uso dei dati di Google

L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Google API Services User Data Policy, compresi i requisiti di uso limitato (Limited Use).

Revoca

L'accesso si può revocare in qualsiasi momento da myaccount.google.com/permissions.
